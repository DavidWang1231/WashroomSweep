# Slides

Eight slides: intro · background · what we built · WiFi demo · camera demo ·
BLE · extensions · summary.

| File | Use |
|---|---|
| `WashroomSweep.pdf` | Present from this. Preview, full screen (⌘⇧F), arrow keys. Works anywhere. |
| `deck.html` | Same deck in a browser. Press **N** for Chinese speaker notes. |

Keynote refuses `.pptx` files generated by python-pptx, so the deck is kept as
HTML and rendered to PDF from it — no PowerPoint round-trip in the loop.

## Adding photos

Three slides have dashed placeholder boxes: the WiFi demo (slide 4), the BLE
scan (slide 6), and any shot of the hardware you want on slide 3.

Edit `deck.html`, replace the `<div class="slot">…</div>` with an `<img>`, then
re-render:

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless \
  --no-pdf-header-footer --print-to-pdf=WashroomSweep.pdf file://$PWD/deck.html
```

The browser blocks nothing locally, so a plain `<img src="photo.jpg">` beside
the HTML file works.
